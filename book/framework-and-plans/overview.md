# กรอบการเตรียมความพร้อมและแผนแม่บทแห่งชาติ

การเปลี่ยนผ่านระบบรหัสลับของทั้งประเทศไม่อาจสำเร็จได้ด้วยความพยายามของแต่ละองค์กรเพียงลำพัง เนื่องจากหน่วยงานต่าง ๆ พึ่งพาโครงสร้างพื้นฐานกุญแจสาธารณะ (Public Key Infrastructure: PKI) โครงข่ายสื่อสาร ผู้ให้บริการ และมาตรฐานร่วมกัน จึงจำเป็นต้องมีทิศทาง กรอบเวลา และกลไกกำกับติดตามระดับชาติ

บทนี้สรุปชุดเอกสารนโยบายด้านความปลอดภัยเชิงควอนตัม (Quantum Security: QS) ที่จัดทำโดยสำนักงานคณะกรรมการการรักษาความมั่นคงปลอดภัยไซเบอร์แห่งชาติ (สกมช.) ได้แก่ (ร่าง) กรอบการเตรียมความพร้อมสู่ความปลอดภัยเชิงควอนตัม พ.ศ. 2569–2578 {cite:p}`ncsa2026qsframework` (ร่าง) แผนแม่บทการเปลี่ยนผ่านสู่ความปลอดภัยเชิงควอนตัม พ.ศ. 2569–2578 และ (ร่าง) แผนปฏิบัติการรายด้าน {cite:p}`ncsa2026qsmasterplan`

```{note}
เอกสารในบทนี้เป็นฉบับร่างเพื่อรับฟังความคิดเห็น สาระและกรอบเวลาอาจเปลี่ยนแปลงในฉบับประกาศใช้ ผู้อ่านสามารถดาวน์โหลดร่างและแสดงความคิดเห็นได้ผ่านระบบกลางทางกฎหมาย (law.go.th) {cite:p}`lawgoth2026qsframeworkhearing,lawgoth2026qsmasterplanhearing`
```

- __กำหนดทิศทางร่วมของประเทศ__: กำหนดหลักการ บทบาท ระยะการเปลี่ยนผ่าน และกลไกการรายงานและทบทวน ให้หน่วยงานภาครัฐ หน่วยงานกำกับดูแล หน่วยงานโครงสร้างพื้นฐานสำคัญทางสารสนเทศ (Critical Information Infrastructure: CII) และภาคเอกชนดำเนินงานสอดคล้องกัน
- __ใช้ PQC เป็นแนวทางหลัก__: ใช้ระบบรหัสลับสำหรับยุคควอนตัม (Post-Quantum Cryptography: PQC) เป็นหลัก และใช้การกระจายกุญแจเชิงควอนตัม (Quantum Key Distribution: QKD) เฉพาะกรณีที่จำเป็นและคุ้มค่า
- __กำหนดกรอบเวลาระดับชาติ__: จัดทำฐานข้อมูลความพร้อมภายใน พ.ศ. 2570 เปลี่ยนผ่านระบบเสี่ยงสูงและระบบ CII ภายใน พ.ศ. 2573 และระบบทั้งหมดภายใน พ.ศ. 2578
- __แปลงนโยบายสู่การปฏิบัติ__: กำหนดชุดงาน ชุดหลักฐาน รูปแบบรายงาน และเกณฑ์การจัดซื้อจัดจ้างที่นำไปใช้ได้จริง
- __สร้างขีดความสามารถของประเทศ__: พัฒนาความสามารถในการทดสอบ รับรอง และประเมินเทคโนโลยีภายในประเทศ รวมถึงพัฒนากำลังคน
